# Направление
Локальный проект, не git-репозиторий. Только новая папка overlay/, старый poodles-overlay не меняется.
Источник стиля: утверждённый мurloc pack, Style B пуделей; пользователь попросил более компактное полупрозрачное болото и синих-золотых солдат. Refero в предыдущем проходе недоступен, используем утверждённые пользовательские ассеты, не новый UI-стиль.
Фиксируем: прозрачный Canvas 1920×1080; болото 230 px (21,3%) с fade и alpha 0.72; персонажи 100–145 px; солдаты 150–175 px; пыль тёплая, брызги бирюзовые. Верх остаётся полностью прозрачным, никаких декоративных панелей в OBS. HUD только demo.
Солдат — новая сгенерированная иллюстрация, без льва/герба/логотипа; исходный публичный референс только для изучения снаряжения, не включать в готовый архив.
